# Codex Lean 0.160.0-lean.2

## Changes

- Parent agents now resume automatically when a child agent finishes, so delegated work can continue without another user message. Idle parents unloaded from memory can also resume within the configured residency limits. Stop and session shutdown prevent automatic resumption. The optional `wait_agent` tool is not required and remains off by default.

## Included in Codex Lean

These features carry forward from the previous fork revision:

- Persistent JavaScript and TypeScript Notebook tools retain variables and reusable helpers across calls and context resets. Saved state restores without replaying commands.
- Notes-based context continuity is the default. Agents checkpoint useful state before starting a fresh context and can retrieve older conversation when needed.
- Shorter instructions, skills loaded on demand, and local `AGENTS.md` discovery leave more context for the work. V2 subagents share tools and a coordination board.
- CLI voice follows public progress and results, refreshes after context rollover, and can recover from a dropped call. Shared personality preferences apply to text and voice. `/settings` and `codex settings` expose the fork's defaults.

Notebook requires full-access permissions in a trusted local project. Notes requires ChatGPT sign-in through the Codex backend. API-key and sandboxed setups can select ordinary compaction and the V8 tool runtime with `codex settings`.
