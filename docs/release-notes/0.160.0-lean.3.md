# Codex Lean 0.160.0-lean.3

## Changes

- CLI and desktop context indicators now show the actual execution ceiling in Notes mode, rather than the smaller working budget. Checkpoint reminders still use the selected working budget. Ordinary compaction is unchanged.
- Agents can ask questions through one tool inside Notebook and Code Mode, either waiting for an answer or continuing other work while awaiting a reply. Native CLI and desktop question interfaces remain supported, including free-text answers. Separate top-level question schemas no longer occupy Code Mode's initial context.
